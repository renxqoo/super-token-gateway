# ADR 0004：网关边界、热点隔离与受控数据演进

状态：代码已实施并完成本地验证；生产容量与真实云验收未完成。2026-11-10 用户授权修复架构评估列出的全部问题，并补 Azure OpenAI、AWS Bedrock、Vertex AI 适配。

保留 PG 预扣、耐久证据队列、worker 原子账务、未知结果待对账及无正文持久化规则。运行时只接受当前数据库契约；离线升级工具负责受支持旧版本的数据转换，不增加旧业务运行路径。

| 单元     | 保留                               | 修正与验收                                                                 |
| -------- | ---------------------------------- | -------------------------------------------------------------------------- |
| 响应计量 | 精确数字、逐尝试证据、原生透传     | 图片对象/分拆载荷计数在 connector 统一解释；验证最终费用                   |
| 模块边界 | 同进程装配、现有公开 HTTP 契约     | HTTP 不写 SQL；报价纯规则与数据库读取分离；供应商传输独立适配              |
| 热点     | 钱包行锁与余额不变量               | 按钱包公平批处理，限制总排队和并发；被锁钱包不阻塞其他钱包                 |
| 云适配   | 现有协议转换与损失拒绝             | Azure 部署寻址、Bedrock 签名/事件帧、Vertex OAuth 刷新；本地合同与失败测试 |
| 数据演进 | 账本与费率不可变、幂等身份永久有效 | 受控停机升级及一致性核验；可验证的归档和留存，不删除未结责任               |
| 运行     | 队列 AOF 与副本确认、失败关闭准入  | 核验候选副本、升级/恢复条件；热点和带副本完整账务压测                      |

顺序：先图片回归与接口收口，再热点调度、云适配、受控升级/归档，最后完整门禁与独立只读审查。每个单元以实际结果补充记录。没有真实云账号或目标故障域时，本地合同/进程故障证据不能替代真实联调和生产 SLO。

回退：代码回退须匹配数据库和队列版本；升级在事务内完成，失败回滚。归档保留校验清单和权威查询入口，不能靠删除审计证据或幂等键缩库。

本地结果：55单元、173集成、编译工具/进程恢复、AOF/副本故障、Linux容器和备份恢复通过；完整证据与容量失败轮次见根 validation.md。10000+ RPS与跨故障域SLO保持未完成。
