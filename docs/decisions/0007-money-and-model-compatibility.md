# 0007 金额契约与模型兼容边界

## 决定

保留 10^-18 币种单位、NUMERIC(38,0)、十进制整数字符串和 BigInt 有理数计算，不新增计算依赖。供应商成本、客户报价和实际收费均按各自捕获的不可变费率，对一个计价对象的全部维度求和后一次向上取整；不得提前按 token、维度或展示位数舍入。该规则不改变历史账单。单次原子化误差小于一个 atom。修改舍入契约需要新的显式迁移决定。

Gateway 是技术钱包，启用币种以已配置的对应币种费率为准，不提供换汇、支付或发票接口。业务系统须维护实际支持的币种和渠道规则；充值传入已确认的整数 atoms。展示金额不能反向覆盖账本。对外收付款在业务系统按币种和渠道最小单位统一量化，记录原始 atoms、实际支付金额及尾差的去向；不得逐次把微计费舍入到分。Gateway 不猜测支付渠道的舍入规则。

缓存写入保留供应商合计 cache_write_tokens，并新增 cache_write_5m_tokens、cache_write_1h_tokens。合计用于总 token 统计和已有合计费率；明细用于不同 TTL 的差异费率，同一费率禁止同时定价合计和任一明细。只有收到的明细可用于计费，缺失值不按零处理，不从历史合计猜测 TTL。完整明细之和必须等于合计，缺少合计但明细完整时可精确求和。新合计快照不得沿用旧明细。SQL 与应用校验采用相同规则。

## 适配与扩展

采用编译期适配注册表，由协议复用请求转换、响应和流处理。每个适配模块声明目标协议、原生操作和请求整形，新增协议仍须同时实现响应、流终态与计量验收。新增同协议模型复用适配模块和路由配置，不为每个模型复制插件。不加载数据库、URL 或用户上传的可执行代码，不提供热更新插件系统。

路由新增 request_policy，按目标原生协议配置 allowed_parameters（顶层参数白名单）、blocked_parameters（点分字段路径，* 匹配数组或对象的一层）和 parameter_ranges（同类路径的 minimum/maximum 数值范围）。空策略保留已有原生透传行为，不表示厂商或模型已经通过真实联调。模型版本、部署与地域用独立路由管理；策略变更审计沿用配置审计。配置校验不扫描工具参数和用户文本，只按指定字段路径执行。

跨协议转换只能处理已声明的字段及嵌套语义，不可表达的 effort、严格模式、缓存控制、未知嵌套字段及非图片媒体返回 422/conversion_loss。原生请求保留扩展字段。路由在客户报价和 PG 预扣前完成转换与策略校验，报价只包含兼容候选；故障切换复用本次已校验的路由快照。Batch 每行同样执行目标路由策略；同一供应商存在多个模型版本时选择整批均兼容的版本，仅捕获该路由与模型输出上限的小快照，重写不重新读取配置、不缓存多份 File。数值范围按实际转发的精确十进制字面量比较，不允许二进制舍入跨过边界。

## 迁移与验收

schema 2026111201 增加路由 request_policy 并更新数字维度校验；由既有离线 --upgrade --quiesced 路径升级，包括 2026111102。升级不改写费率、历史用量、账单或余额。新增 TTL 费率只能在新版本应用与 worker 全部部署后启用；回退旧应用前必须停用新维度费率并排空新维度作业，不支持旧版本读取新维度。

回归覆盖嵌套参数丢失、媒体误转换、混合 TTL 精确计价和缺证保留预扣、合计明细重复收费、路由筛选与策略变更、历史 schema 升级。厂商真实账号验收另按模型版本维护请求、响应、流终态和用量样例；mock 通过不宣称全模型兼容。运行项目全部规定门禁并独立审查。
