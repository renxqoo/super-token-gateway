# ADR 0013 个人与团队计费账户

2026-11-25，个人与团队计费账户。

## 决定

个人注册和团队创建各自动开通一个计费账户。个人所有者和团队成员按角色管理 Key、用量和钱包。Key 签发时固定付款账户。每个 Key 可以设置模型、操作、来源 IP 和消费上限，并可轮换或撤销。普通 Key 只能访问同一轮换链签发的任务。账户 ADMIN 可查询或取消本账户内符合当前 Key 策略的任务。取消在更新前重新核对 Key 权限。

## 实施与验收

| 范围               | 现行契约                                                                          | 验收                                                  |
| ------------------ | --------------------------------------------------------------------------------- | ----------------------------------------------------- |
| Console 和 Gateway | 使用 `billing_account_id` 签发、扣费、查账和记录用量                              | HTTP 验证个人钱包和团队钱包分别扣费，以及凭证权限隔离 |
| PostgreSQL         | Gateway、Console 各用独立的空数据库初始化，Trace 启用时单独建库                   | 空库启动、重复执行初始化、拒绝非现行数据库            |
| Outbox             | 按计费账户分片，按消费者和分片记录租约与进度。事件与告警使用 `billing_account_id` | 真实 PostgreSQL 验证认领、确认、重试与告警            |
| Redis 和幂等       | 以计费账户为范围计算限流键和新请求指纹                                            | 多副本限流、推理和资金请求重放                        |

## 发布

按部署手册创建新库并配置应用连接。已有数据库继续作为历史记录。历史余额、Key 和账单的转移需另行实施并独立核对。具体步骤见 [部署与验收](../console-api.md#部署与验收)。
