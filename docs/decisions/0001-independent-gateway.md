# ADR 0001：独立 Gateway

2026-11-10，历史决策。**钱包、售价、预扣、结算及退款的归属已由同日后续用户澄清和 [ADR 0002](0002-gateway-wallet-worker.md) 覆盖；以下保留决策历史，不再约束资金实现。**

Gateway 自有项目、技术凭证、模型、渠道、路由、请求尝试、usage 与资源标识。
商业用户、组织、套餐、销售价格、现金钱包、支付、退款及客户收费属于未来独立业务系统。
Gateway 不导入业务系统实现，不查询其数据库，不在请求路径同步调用资金服务。
通过管理 API 配置 Gateway，通过耐久、认领/确认式 usage 事件与业务系统集成。

输出前允许有界切换，包括可能已执行的调用；每次物理尝试单独记录，不能把旧尝试抹去。
输出开始后禁止透明切换。UNKNOWN、PARTIAL、FINAL 用量分别保存，不将缺失用量视作零。
Gateway 只算版本化上游成本，不决定客户应收、免收与退款。

任何 LLM 输出正文、向量、媒体、工具参数、Batch 输出和完整供应商响应不得写入数据库、文件、日志或事件。
数据库仅保存访问配置、ID/归属/状态、用量、精确成本与内容无关的审计事件。
输入文件上传仅有界内存处理并转交上游；输出文件/视频下载直接有界代理。
查询/重放内容依赖上游保存能力，Gateway 不提供本地响应缓存。

原始 13 份设计完整备份在 ../design-2026-11-08，manifest.json 包含原始 SHA-256。
其中资金调用前置、永久免收状态和响应归档设计不适用于当前 Gateway，不能作为实现验收条件。
