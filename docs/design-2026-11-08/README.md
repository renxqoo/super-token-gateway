# New Gateway：全新架构设计

日期：2026-11-08 · 版本：1.1 · 项目类型：从零建设 · 状态：待实施设计。

[下载完整文档包](design-documents.zip)

目标是持续 10,000+ 业务请求/秒的多供应商模型网关，具备准确计量、严格预扣、幂等收费、智能路由与可恢复的供应商成本管理。本目录定义新的运行边界、接口、数据模型和状态机，不包含旧项目迁移或兼容要求。

已确定技术方案：Bun + TypeScript 执行节点、资金服务及后台处理器 + PostgreSQL 资金分片 + Redis 路由/软配额 + 加密对象存储。首版使用 Bun.serve、Web Streams、Bun.SQL 与 PG 耐久工作表；独立进程扩展，金融任务不依赖进程内 Promise 或内存队列。具体版本须锁定并通过兼容验收，无需先引入 Kafka 或 BullMQ。

保证边界：本地资金变更原子、可重放、不可重复收费；上游执行未知时不伪造 usage。用户免收与供应商成本是独立决策，平台未知成本有预先分配的风险预算。万级吞吐与故障保证须按验收条件实测，本文不宣称已经达标。

Tillgate 只提供设计启发：资金原语、不可变价格快照、资金来源分配、消费认领和路由评分。这里没有沿用其包、API、表、状态词表、金额格式或部署约束，也不继承其测试结果。
