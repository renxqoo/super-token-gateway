# 本地参考对照

本轮使用用户指定的 work/Tillgate、work/new-api，只读核对。通过 `bun run references:snapshot -- --output .local/credit-capacity-20261111/references.json` 保存当前版本、工作区状态和关键源码SHA-256。该命令不运行性能测试，也不推导排名。

| 能力                         | Tillgate 的当前证据                                | new-api 的当前证据                             | 本项目当前交付与验收                                                          |
| ---------------------------- | -------------------------------------------------- | ---------------------------------------------- | ----------------------------------------------------------------------------- |
| 资金预扣                     | billing 的资金来源预扣和结算                       | request_billing / BillingSession               | PG 原子资金/信用预扣及幂等结算，分别核对来源与债务                            |
| 授信/地板                    | exposure 与 debit-floor 区分正常授信及结算补扣地板 | 本轮未作等价授信契约确认                       | 正常授信默认0，在途信用计入敞口；异常全额应收可超限并冻结，无结算宽限或硬封顶 |
| 精度                         | Decimal 与存储金额串                               | quota整数及价格换算，具体路径须分别核对        | BigInt/有理数、NUMERIC38、最后一次取整，不从语言类型直接推导参考项目不安全    |
| Rerank                       | inference-endpoints.ts 有入口                      | relay-router.go 有入口                         | 当前不支持，明确协议差距                                                      |
| Realtime/Responses WebSocket | 本轮未确认                                         | relay-router.go 有入口                         | 当前不支持，明确协议差距                                                      |
| 幂等及未知恢复               | 需要相同故障注入下对照                             | 进程内BillingSession状态不能替代持久化恢复验证 | PG持久身份、数字证据队列、未知保留、重复结算及晚到补证回归                    |
| 6000 RPS                     | 当前版本未做同契约复测                             | 当前版本未做同契约复测                         | 本轮按容量契约实测后填写，不引用旧职责链路排名                                |

Tillgate 已有的结算透支地板不能视为本项目已支持；new-api 的信任额度旁路、各系统退款/结算完成时机、正文留存和耐久策略必须在性能对照时披露。没有等价配置时报告各自行为与资源成本，不用较弱资金保证换取“更快”结论。

本轮对标的交付范围是资金语义及完整链路验收，不包含支付、商业控制台或新增WebSocket/Rerank协议。后续每次容量或协议变化重新记录参考版本并更新矩阵，功能缺口关闭前不宣称“全面超过”。
